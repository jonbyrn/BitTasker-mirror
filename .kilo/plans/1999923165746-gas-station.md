# GasStation — Gasless USDT0-to-rBTC via Meta-Transaction Relay (v3)

## Goal

Users with zero ETH on Arbitrum swap USDT0 → rBTC. One signature. One click.

---

## Architecture

```
User (no ETH, has USDT0)
     │
     │ 1. signs EIP-712 { usdtAmount, maxGasUsdtIn, targetCalldata, deadline, nonce }
     │    └─ one signature (no separate permit — USDT0 lacks EIP-2612)
     │
     │ 2. pre-approve GasStation for USDT0 spend (done once, ~$0.05 ETH tx)
     │
     │ 3. POST signed payload → Cloudflare Worker relayer (Durable Object queue)
     │
     ▼
Cloudflare Worker (relayer, Durable Object serial queue)
     │
     │ 4. Verifies: maxGasUsdtIn >= estimatedGasCost * 1.2 (20% buffer)
     │ 5. Re-fetches LI.FI quote (calldata stale after client fetch)
     │ 6. Submits via DO (serialized, 120s timeout, exponential gas escalation)
     │ 7. Waits for tx receipt (30-120 sec)
     │ 8. Returns final tx hash to user (or error)
     │
     ▼
GasStation Contract (Arbitrum, immable, no upgrade, no admin)
     │
     │ A. ReentrancyGuard.lock()
     │ B. EIP-712 sig verify (chainID + address + nonce + deadline)
     │ C. nonces[signer]++
     │ D. SafeERC20.safeTransferFrom(signer, address(this), usdtAmount)
     │ E. gasStart = gasleft()
     │ F. swapExactOutput(USDT0, WETH, relayerGasCostWei, maxGasUsdtIn, pool)
     │    └─ implements uniswapV3SwapCallback — pulls USDT0 from contract
     │ G. gasCostWei = valid gas cost
     │ H. payable(tx.origin).transfer(min(gasCostWei * 110/100, maxGasFeeWei))
     │ I. remaining = usdt0.balanceOf(address(this))
     │ J. SafeERC20.safeApprove(USDT0, LIFI_DIAMOND, remaining)  ← approve AFTER gas swap
     │ K. (bool ok, ) = LIFI_DIAMOND.call(calldata_)             ← LI.FI swap
     │ L. require(ok, "swap failed")
     │ M. uint256 refund = usdt0.balanceOf(address(this))
     │ N. SafeERC20.safeTransfer(signer, refund)
     │ O. ReentrancyGuard.unlock()
```

**Critical design decisions (v3, resolved from audit):**

| # | Decision | Why |
|---|----------|-----|
| 1 | `tx.origin` identifies relayer | Can't be spoofed, always the submitting EOA |
| 2 | No off-chain price needed | `exactOutput` swap on Uniswap V3 — relayer sends `gasCostWei` as output target, contract swaps exact USDT0 |
| 3 | `maxGasUsdtIn` is signed parameter | User caps max USDT0 spent on gas. Renamed from v2's confusing `minUsdt0Out` |
| 4 | Approve LI.FI Diamond AFTER gas swap | Contract balance is reduced by gas swap amount — approve exact remaining balance |
| 5 | Uniswap V3 callback pattern | `uniswapV3SwapCallback` required — contract pulls USDT0 via callback during swap |
| 6 | EIP-2612 permit NOT used | USDT0 on Arbitrum lacks `permit()`. Users must pre-approve once (`~$0.05`) |
| 7 | 1.1x gas buffer IN THE CONTRACT | `min(gasCostWei * 110/100, maxGasFeeWei)` — relayer gets 10% over actual cost |
| 8 | Relayer re-fetches LI.FI calldata | LI.FI quotes expire in 30-60s — client fetches stale, relayer fetches fresh |

#### execute() — single entry point
```solidity
function execute(GasStationCalldata calldata calldata_) external nonReentrant {
    // 1. Deadline + nonce checks
    require(block.timestamp <= calldata_.deadline, "expired");
    require(nonces[calldata_.signer] == calldata_.nonce, "bad nonce");
    _verifySignature(calldata_);
    nonces[calldata_.signer]++;

    // 2. Pull USDT0 from user
    SafeERC20.safeTransferFrom(usdt0, calldata_.signer, address(this), calldata_.usdtAmount);

    // 3. Gas swap: USDT0 → WETH on Uniswap V3
    //    exactOutput — relayer receives specific gasCostWei worth of ETH
    uint256 gasStart = gasleft();
    uint256 actualGasCostWei = _computeGasCost();
    uint256 reimbursableWei = Math.min(actualGasCostWei * 110 / 100, calldata_.maxGasUsdtIn);
    _swapExactOut(pool, reimbursableWei);  // via uniswapV3SwapCallback

    // 4. Reimburse relayer
    payable(tx.origin).transfer(address(this).balance);

    // 5. Approve Diamond for remaining balance (after gas consumed)
    uint256 remaining = usdt0.balanceOf(address(this));
    SafeERC20.safeApprove(usdt0, LIFI_DIAMOND, remaining);

    // 6. Execute LI.FI swap
    (bool ok,) = LIFI_DIAMOND.call(calldata_.targetCalldata);
    require(ok, "swap failed");

    // 7. Return leftover USDT0 (if any)
    remaining = usdt0.balanceOf(address(this));
    if (remaining > 0) SafeERC20.safeTransfer(usdt0, calldata_.signer, remaining);
}

function uniswapV3SwapCallback(int256 amount0Delta, int256 amount1Delta, bytes calldata) external {
    require(msg.sender == address(pool), "invalid callback");
    // Pay USDT0 to pool from this contract's balance
    uint256 usdtToPay = amount0Delta > 0 ? uint256(amount0Delta) : uint256(amount1Delta);
    SafeERC20.safeTransfer(usdt0, msg.sender, usdtToPay);
}
```

#### Security table

| # | Measure | Why |
|---|---------|-----|
| 1 | EIP-712 with `block.chainid` + `address(this)` + `nonce` | Cross-chain + same-chain replay protection |
| 2 | `deadline` | Stale execution protection |
| 3 | `maxGasUsdtIn` (signed cap) | Relayer can't extract more USDT0 than user authorized |
| 4 | ReentrancyGuard | `execute()` is non-reentrant |
| 5 | `tx.origin` | Immutable relayer ID — no param manipulation |
| 6 | SafeERC20 | Non-standard USDT0 return |
| 7 | Immutable, no admin, no `selfdestruct` | Can't be rug-pulled |
| 8 | Gas swap BEFORE Diamond approve | Contract balance is correct at approve time |
| 9 | 1.1x gas buffer | Relayer gets slight over-reimbursement — compensates for gas cost variance |
| 10 | `uniswapV3SwapCallback` validates `msg.sender == address(pool)` | Prevents fake callback attacks |
| 11 | Remaining check: `if (remaining > 0)` | Handles zero balance gracefully |

### 2. `src/services/gas-station-relayer.ts` (~150 lines)

Cloudflare Worker with Durable Object for serialized tx submission.

```typescript
export class RelayQueue {
    private pendingTx: Promise<string> | null = null;

    async enqueue(request: RelayRequest): Promise<string> {
        const timeout = new Promise<never>((_, reject) =>
            setTimeout(() => reject(new RelayError('queue_timeout')), 120_000));
        
        while (this.pendingTx) await Promise.race([this.pendingTx, timeout]);
        
        this.pendingTx = this.submitAndWait(request);
        const result = await this.pendingTx;
        this.pendingTx = null;
        return result;
    }

    private async submitAndWait(request: RelayRequest): Promise<string> {
        // 1. Re-fetch LI.FI calldata (client's copy is stale)
        const freshCalldata = await lifiService.getStepTransaction({
            fromChain: 42161, toChain: 30,
            fromToken: USDT0_ARB, toToken: NATIVE,
            fromAmount: String(request.usdtAmount),
            fromAddress: GAS_STATION_ADDRESS // contract will hold the USDT0
        });

        // 2. Verify maxGasUsdtIn >= estimatedGasCost * 1.2 (20% buffer)
        const tx = { to: GAS_STATION_ADDRESS, data: encodedGasStationCall, gasLimit: 800_000n };
        const gasEstimate = await provider.estimateGas(tx);
        const fees = await provider.getFeeData();
        const gasCostWei = gasEstimate * fees.maxFeePerGas;
        if (request.maxGasUsdtIn < gasCostWei * 120n / 100n) {
            throw new RelayError('gas_too_high');
        }

        // 3. Submit with exponential gas price escalation
        let maxFee = fees.maxFeePerGas * 120n / 100n;
        const txHash = await this.sendWithRetry(tx, maxFee);

        // 4. Wait for confirmation
        const receipt = await provider.waitForTransaction(txHash, 1, 120_000);
        if (receipt.status === 0) throw new RelayError('tx_reverted');

        return txHash;
    }

    private async sendWithRetry(tx: any, maxFee: bigint): Promise<string> {
        const attempts = [{ price: maxFee }, { price: maxFee * 125n / 100n },
                         { price: maxFee * 150n / 100n }, { price: maxFee * 200n / 100n }];
        for (const attempt of attempts) {
            try {
                const { hash } = await relayerWallet.sendTransaction({ ...tx, maxFeePerGas: attempt.price });
                return hash;
            } catch { /* wait 10s, retry with next price */ }
            await new Promise(r => setTimeout(r, 10_000));
        }
        throw new RelayError('tx_submission_failed');
    }
}
```

### 3. `src/api/services/GasStationService.ts` (~90 lines)

```typescript
class GasStationService {
    async executeSwap(usdtAmount: bigint): Promise<{ txHash: string }> {
        // 1. Estimate gas for GasStation (off-chain)
        const gasEstimate = 600_000n;
        const fees = await arbProvider.getFeeData();
        const maxGasUsdtIn = gasEstimate * fees.maxFeePerGas * 120n / 100n
            * estimateUsdtPerEth / 1e18 * 110n / 100n; // convert to USDT0 + overhead

        // 2. Build + sign EIP-712 (ONE signature)
        const message = {
            signer: userAddress, usdtAmount, maxGasUsdtIn,
            targetCalldata: '0x', // placeholder — relayer will re-fetch
            deadline: Math.floor(Date.now() / 1000) + 300,
            nonce: await gasStation.nonces(userAddress)
        };
        const signature = await signer.signTypedData(domain, types, message);

        // 3. Submit to relayer
        const resp = await fetch(RELAYER_URL, { method: 'POST',
            body: JSON.stringify({ message, signature }) });
        if (!resp.ok) throw new RelayError((await resp.json()).reason);
        return resp.json(); // { txHash }
    }
}
```

## Pre-approval Flow (USDT0 lacks `permit()`)

| Step | Action | Gas |
|------|--------|-----|
| 1 | User signs "one-time approve GasStation to spend USDT0" meta-tx | 0 |
| 2 | Relayer submits approve tx | ~$0.05 (ETH) |
| 3 | User proceeds with any number of swaps (no further approvals) | GasStation handles |

The pre-approval is a one-time cost per user. For first-time users, the GasStation contract can handle the approval expense: the user signs a meta-tx with a small extra `approvalGasUsdt` deduction. The GasStation contract checks allowance → if 0, executes approve first, deducting $0.05 USDT0 from the swap amount.

## Cost Summary ($5 USDT0 → rBTC, 600k gas baseline)

| Item | Cost |
|------|------|
| Gas (600k × 0.1 gwei) | ~$0.12 |
| Uniswap swap (USDT0→ETH) | ~$0.01 |
| Service fee | ~$0.01 |
| **Total user pays** | **~$0.14** |
| User receives in rBTC | **~$4.84** |

0.1 ETH relayer fund → ~800 swaps before refill. At 100 swaps/day, refill every 8 days.

## Deployment

1. Deploy `GasStation.sol` to Arbitrum mainnet (once, immutable)
2. Fund relayer wallet (0.05 ETH hot wallet, auto-refilled from 0.1 ETH cold wallet via cron)
3. Set Worker secrets: `RELAYER_PRIVATE_KEY`, `GAS_STATION_ADDRESS`
4. Cron monitor: if `relayerBalance < 0.02 ETH → alert + trigger refill`

## Open Questions (resolved from all audit rounds)

| Issue (from v1) | Resolution (v3) |
|-----------------|-----------------|
| amountOutMin = 0? | → Signed `maxGasUsdtIn` parameter (renamed from confusing `minUsdt0Out`) |
| Gas formula placement? | → Gas computed once after pull, before swap |
| Relayer address? | → `tx.origin` |
| Units mismatch? | → exactOutput swap — no off-chain price needed |
| Off-chain price oracle? | → Removed entirely |
| Concurrency? | → Durable Object serial queue with 120s timeout |
| EIP-2612 permit? | → One-time approve flow (documented) |
| LI.FI approve? | → Moved to AFTER gas swap — approve exact remaining balance |
| LI.FI balance after gas swap? | → approve amount = remaining balance after swap |
| `arbEthBalance === 0`? | → Threshold: `< MIN_ETH_FOR_SWAP` |
| Return tracking? | → `balanceOf` with safety check |
| Two signatures? | → Single EIP-712 |
| No confirmation state? | → 3-phase status |
| Relayer profit? | → 1.1x gas buffer covers variance; $0.01 service fee |
| Multi-relayer? | → `tx.origin` allows anyone to relay |
| Gas escalation? | → 4-attempt escalation chain (120% → 125% → 150% → 200%) |
| DO queue timeout? | → 120s `Promise.race` prevents wedging |
| LI.FI calldata stale? | → Relayer re-fetches just before submission |
| Balance monitoring? | → Cron: if < 0.02 ETH, alert + auto-refill |
| Uniswap V3 callback? | → `uniswapV3SwapCallback` validated against `msg.sender == address(pool)` |
