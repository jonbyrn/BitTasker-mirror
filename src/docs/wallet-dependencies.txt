# BitTasker Wallet Dependencies

## Core Bitcoin Libraries
- bitcoinjs-lib: Bitcoin transactions and address generation
- bip39: Mnemonic phrase generation
- bip32: HD wallet derivation
- buffer: For browser compatibility // NOT WORKING - USE DEFAULT JS UTILITIES

## Mobile Features: DEPENDENCIES ALREADY EXISTS
- @capacitor/core: Capacitor core functionality
- @capacitor/device: Device information and security
- capacitor-native-biometric: Biometric authentication

## Lightning Network (Optional - Future Implementation)
- webln: Web Lightning interface
- @getalby/bitcoin-connect: Bitcoin Connect for wallet connection
- @getalby/js-sdk: Lightning wallet SDK

## Utility Libraries
- qrcode: QR code generation
- @zxing/library: QR code scanning
- @zxing/browser: Browser integration for QR scanning

## Install Command
```bash
npm install bitcoinjs-lib bip39 bip32 qrcode
```

## Optional Lightning Integration (Future)
```bash
npm install webln @getalby/bitcoin-connect @getalby/js-sdk
```

## QR Code Scanning (if needed)
```bash
npm install @zxing/library @zxing/browser
```
