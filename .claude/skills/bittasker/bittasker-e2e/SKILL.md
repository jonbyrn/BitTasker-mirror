# E2E Testing — BitTasker

## Playwright MCP Tools

- `browser_navigate`, `browser_click`, `browser_type` — UI interaction
- `browser_snapshot`, `browser_take_screenshot` — page inspection
- `browser_network_requests` — API call inspection

## Commands

```bash
npm run test:e2e    # Full Playwright e2e suite
```
